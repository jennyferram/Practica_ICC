1 Psicologo (5 pts)
1.1 Objetivo

El objetivo de esta práctica es que el alumno se familiarice con la creación y uso de ob-
jetos de la clase String utilizando algunos métodos de dicha clase en la elaboración de un
programa.
1.2 Descripción general
La práctica consiste en utilizar cadenas de caracteres y algunos de los métodos de dicha
clase en la elaboración de un programa para simular una sesión con un psicólogo.

#CONTENIDO
Psicologo.java: Programa que simula una conversación entre un psicólogo y un usuario. En este programa utilizamos impresiones por pantalla, datos de entrada y de salida.

2 RFC (5 pts)
2.1 Descripción general

La práctica consiste en utilizar cadenas de caracteres y algunos de los métodos más impor-
tantes de dicha clase en la elaboración de un programa para generar una clave al estilo del
RFC de las personas.

#CONTENIDO
RFC.java: Programa que manipula cadenas de caracteres para obtener el RFC.
